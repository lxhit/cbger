# Results

- `main/table2_cbger.csv`: clean final-name main table.
- `main/table2_main_results.json`: complete original paper-stage summaries and user-cluster bootstrap significance tests.
- `main/cbger_three_seed_summary.json`: final CBGER three-seed metrics.
- `ablations/mean_pooling_factorial.json`: Structured CF × mean-pooling 2×2 ablation.
- `ablations/aggregation_rules.json`: max, Top-K, learned and mean Whether aggregators.
- `baselines/*`: per-seed and aggregate baseline metrics.

Historical PBGER labels are preserved in original JSON/Markdown artifacts for traceability. The public names are CBGER-10K and CBGER.
